# Pilot

An interactive web app for exploring Predictive Index (PI) behavioral assessment reports.

A PI report on its own is a static document. Pilot turns it into a conversation: read your behavioral pattern in a clean interface, then use the built-in AI chat to dive deeper into your drives, needs, and work style, and turn the insights into practical next steps for personal growth and success.

## What it does

- Presents PI report analysis in a readable, visual interface
- Personalized AI chat focused on your own behavioral profile
- Built for individuals exploring their results, and for coaches or teams discussing them together

## Tech stack

- Next.js 16 and React 19
- TypeScript
- Tailwind CSS 4

## Getting started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
